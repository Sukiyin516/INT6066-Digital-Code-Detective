# 数字迷案 · V3

《数字迷案》是一款面向小学三年级的离线侦探游戏。学生通过观察身份证复印件和信封，学习如何读懂编码，再用收集到的线索核对嫌疑人资料。

## V3 版本更新

| 功能 | V3 更新内容 |
| --- | --- |
| 第一关任务提示 | 左下角统一显示「锁定真正的嫌疑人」，按 0/3、1/3 至 2/3、3/3 显示不同的调查引导。 |
| 证物 A · 残缺身份证 | 新增暖色侦探提示卡和彩色身份证编码知识图。点击「开始解密」后，可同时对照知识图和证物作答。答对的线索会自动收入侦探笔记。 |
| 证物 B · 未寄出的信 | 先展开彩色邮编知识卡，再从图下的「新的调查任务」进入查询簿。 |
| 邮编查询簿 | 新增查询任务卡和成功结果卡。学生主动查询后，才会看到结果及「调查嫌疑人」入口。成功查到本案信封的邮编后，结果会自动存入侦探笔记。 |
| 侦探笔记 | 第一关只展示已解出的线索和实际打开过的知识 Tip。知识卡可回看，已收集线索刷新后仍可恢复。 |

V3 聚焦第一关的学习和调查体验。原有题目、答案判定、通关条件及第二关流程沿用原设计。

## 如何游玩

1. 下载并解压整个项目，双击 `index.html` 或 `打开游戏.cmd`。可以用 Chrome 或 Edge，无需联网或安装依赖。
2. 阅读案件说明，进入调查室，点击放大镜查看证物和书架资料。
3. 打开证物 A 的知识 Tip，点击「开始解密」，对照知识图和证物作答。
4. 打开证物 B 的知识 Tip，学习邮编知识后进入查询簿，输入信封上的邮编。
5. 查看六位嫌疑人的资料，提交调查报告。第一关完成后可继续追查红宝石。

调查进度保存在当前浏览器。请保留完整目录结构，以便游戏找到图片和其他资源。要开启新一轮调查，可以点击「重新开始」并确认。

## 开发与验证

- `index.html` 是游戏入口。界面样式在 `styles.css`、`scene.css` 等文件中。
- `app.js` 管理界面交互和存档，`data.js` 提供游戏资料，`rules.js` 负责判题规则。
- `assets/` 存放游戏实际加载的知识卡和调查室背景。
- 规则测试：`node --test tests/rules.test.cjs`
- 浏览器测试：安装 Playwright 和 Chromium 后运行 `node tests/browser.test.cjs`。如需指定本机路径，可设置 `PLAYWRIGHT_PACKAGE` 和 `BROWSER_PATH`。
