# 数字迷案 谁是嫌疑人

本地离线运行的 HTML / CSS / JavaScript 点击式解谜游戏。严格依据同目录《INT6066_数字迷案_游戏开发规格_v1.md》实现第一轮可玩版本。

当前主调查场景使用已经确定的 `detective-room-background.png`，原图直接复制到 assets，不作重绘或修改。五个发光放大镜为 HTML/CSS 按钮，按百分比对齐笔记、身份证、信封、六人板及右侧书架。场景内左上笔记入口、右上提交入口、左下任务 HUD；进度按身份证、信封、邮编查询簿三项资料计算，重复查看不重复计数。弹窗沿用已有的简单结构及完整交互。

## 本地打开

直接双击 `index.html`，使用 Chrome、Edge 或其他支持 HTML dialog 的现代浏览器打开即可。不用安装依赖、不用联网、不用启动服务器。

也可以双击 `打开游戏.cmd`。请保留整个目录结构，不能只复制 index.html。

## 游玩流程

1. 阅读案件说明，进入调查室。
2. 自由点击身份证、信封、资料柜的 HTML 放大镜按钮。知识 Tip 默认折叠，点击标题可展开知识点，再点可收起。展开过的 Tip 会收入侦探笔记。
3. 打开六人调查板，根据自己的判断暂时排除、恢复或选择人物。
4. 侦探笔记可以回看已发现资料和已查看的 Tip，也可以记录自己的推理。
5. 提交调查报告，同时选择人物和判断依据。失败后保留调查记录，可继续核对并重试；成功后显示学习回顾及隐私提醒。

Tab 可以在按钮间移动，Enter / 空格激活按钮，Esc 关闭弹窗。弹窗支持键盘焦点约束与返回原入口。页面兼容桌面、平板和手机，课堂投影建议使用桌面横屏。

## 保存与重新开始

证物浏览记录、Tip、笔记、排除标记及报告选择会保存在当前浏览器的 localStorage 中。换浏览器或换文件路径可能不会共享记录。浏览器禁用存储时，本次页面中的游戏仍然可用，但刷新后无法保留。

点击“重新调查”，确认后清空本案进度。课堂轮换学生时建议重新调查；不要在笔记中输入真实个人身份资料。

## 文件结构

- `index.html`：场景入口和弹窗容器。
- `styles.css`：界面、响应式布局及 HTML/CSS 放大镜。
- `scene.css`：当前背景主场景、固定按钮、任务 HUD 及百分比热点布局。
- `data.js`：故事、六人资料、证物、Tip、短题及报告选项。
- `rules.js`：判题和排除切换逻辑，与界面分离。
- `app.js`：场景交互、表单、笔记及本地存储。
- `assets/detective-room-background.png`：当前实际使用的背景，与上级目录中用户确定的同名原图内容一致。
- `assets/room.svg`：保留的旧占位图，当前不加载。原 `okmockup.png` 也不加载。
- `tests/`：规则测试和真实浏览器交互测试。
- `test-results/`：浏览器测试生成的截图，仅用于检查。

背景尺寸为 1672 × 941。背景与所有场景控件都在 position: relative 的 game-stage 内，按钮、标题、HUD 和热点均以它为绝对定位参照。场景完整等比缩放，控件尺寸与字体使用场景宽度单位 cqw 同步缩放；HUD 位于图片左下角，避开桌面证物。不再给浏览器窗口固定控件或预留独立的 HUD 区域。原生模态弹窗继续使用原有居中与滚动行为。以后更换构图或比例时，需要同步调整 index.html 的热点百分比及 scene.css 的画幅比例。不要将放大镜或泄露答案的号码、照片画入背景。

## 测试

规则测试（需要 Node.js）：

```powershell
node tests/rules.test.cjs
```

浏览器测试需要已有的 Playwright 和 Chromium。可通过环境变量指定依赖位置及浏览器位置；这些依赖仅用于测试，游戏本身不需要。

```powershell
$env:PLAYWRIGHT_PACKAGE = '你的 Playwright 包绝对路径'
$env:PLAYWRIGHT_BROWSERS_PATH = '你的 Playwright 浏览器目录'
node tests/browser.test.cjs
```

也可设置 `BROWSER_PATH` 为测试用 Chromium 可执行文件路径。

测试范围：全部 96 种人物及理由组合、固定资料与身份证位置、撤销排除、离线 file 打开、证物与 Tip、两道短题、邮编查询、笔记刷新恢复、错误反馈不泄露对象、重试、通关、移动端溢出、键盘操作及重新开始。

## 第一轮边界

场景和人物为占位美术，未使用 Three.js、后端、真实 AI、登录、计时或排行榜。最终通过条件与原规格一致，代码未自动代替学生排除人物。没有增加主线之外的谜题。
